# progress-report

Weekly progress reports, one file per week, committed the week they're due.

Per the course brief (section 4.1e): a progress report only counts if the
commit history for that week also shows project activity. Uploading a report
for a week with no other commits is treated as not completed, so this folder
being updated is not a substitute for regular commits elsewhere in the repo,
it's additional to them.

Suggested naming: `YYYY-MM-DD-week-N.md` (Monday of the reporting week, or
the date the report is actually written).
