Thành phầnLựa chọn
Nền tảng web.NET 10, ASP.NET Core MVC, Razor views
Dữ liệuEntity Framework Core (Code-First, migrations), SQLite khi phát triển, schema theo kiểu SQL Server
Tài khoảnASP.NET Core Identity trên bảng Users của đặc tả, OTP qua email (MailKit, Gmail SMTP)
Báo cáoClosedXML (xuất Excel), trang in của trình duyệt (PDF)
Kiểm thửxUnit, WebApplicationFactory, Playwright (trình duyệt thật)
Quản lý mã nguồnGit, GitHub, mỗi chức năng một nhánh và một pull request
Nền tảng là .NET 10 với ASP.NET Core MVC. Dữ liệu dùng EF Core theo kiểu Code-First, khi phát triển chạy SQLite nhưng kiểu dữ liệu đặt theo SQL Server để sau này chuyển sang dễ dàng. Tài khoản dùng ASP.NET Core Identity. Kiểm thử có hai lớp: xUnit chạy app trong bộ nhớ, và Playwright điều khiển trình duyệt thật.
