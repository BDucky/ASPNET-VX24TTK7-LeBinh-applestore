# thesis

Project document files, per the course brief (section 4.3). Subfolders:

| Folder | Contents |
|---|---|
| `doc/` | Documents in `.DOC`/`.DOCX` format |
| `pdf/` | Documents in `.PDF` format |
| `html/` | Web-format documents |
| `abs/` | Report abstract/slides, e.g. `.PPT`, `.AVI` |
| `refs/` | Reference material, named by citation or memorable name |
| `soft/` | *(if any)* Related software used during the project |
| `docker/` | *(if any)* Docker deployment files |

`soft/` and `docker/` are created only once there is something to put in
them, per the brief ("neu co" / if any).
