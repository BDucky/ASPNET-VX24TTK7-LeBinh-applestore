# scr

This folder exists to satisfy the course brief's literal directory-tree
requirement (section 4.3), which names the source folder `scr`. This repo's
actual source code lives under [`../src/`](../src/), organized as
`AppleStore.Domain` / `AppleStore.Infrastructure` / `AppleStore.Web`, see
`../README.md` and `../docs/architecture.md` for the real layout.

Test data files that belong specifically to this bucket (per the brief) can
go here as they're produced; application source stays in `../src/`.
